# Qonys.kz

Площадка подселения и аренды комнат в Казахстане: лента объявлений, личный кабинет с балансом, платное продвижение и полноценная админка.

Стек: **Next.js 14 (App Router) · TypeScript · Prisma · PostgreSQL · NextAuth · Tailwind CSS**

---

## Что внутри

**Витрина**
- Лента объявлений с фильтрами: район, тип жилья, пол соседа, бюджет
- Карточка объявления с профилем автора, привычками и удобствами
- Контакты скрыты до оплаты — номер открывается один раз на объявление
- Жалоба на объявление в один клик
- Страницы: тарифы, безопасность, правила размещения, о сервисе

**Личный кабинет клиента** (`/cabinet`)
- Обзор: просмотры, открытия контактов, расходы на продвижение
- Мои объявления: поднять, продвинуть, в архив, удалить
- Баланс: пополнение, история операций, история платежей
- Тариф риелтора: подключение и продление
- Профиль: возраст, занятость, о себе

**Админка** (`/admin`)
- Дашборд: выручка за месяц и за всё время, разбивка по услугам
- Модерация: очередь с публикацией и отклонением с причиной
- Объявления: поиск, фильтр по статусу
- Пользователи: блокировка, назначение модератора, ручная корректировка баланса
- Платежи: все транзакции провайдера
- Тарифы и пакеты: цены редактируются прямо в интерфейсе
- Жалобы и настройки площадки

## Модель монетизации

| Источник | Как работает | Где настраивается |
|---|---|---|
| Продвижение объявления | ТОП, «Срочно», выделение цветом, поднятие, фотопакет | `/admin/tariffs` → Пакеты |
| Тарифы риелторов | Старт / Бизнес / Про — лимит объявлений, бесплатные поднятия, аналитика | `/admin/tariffs` → Тарифы |
| Открытие контактов | Разовое списание с того, кто смотрит номер | `/admin/settings` → `contact_unlock_price` |
| Лимит бесплатных размещений | Сверх лимита — только по тарифу | `/admin/settings` → `free_listings_per_user` |

Все списания идут через внутренний кошелёк (`Wallet`) с записью каждой операции в `Transaction`. Бонусные тенге тратятся первыми и не выводятся.

## Быстрый старт

```bash
git clone https://github.com/<ваш-аккаунт>/qonys-kz.git
cd qonys-kz
npm install

cp .env.example .env          # заполните DATABASE_URL и NEXTAUTH_SECRET
openssl rand -base64 32       # сгенерируйте NEXTAUTH_SECRET

docker compose up -d db       # или свой PostgreSQL
npx prisma db push
npm run db:seed               # районы, тарифы, пакеты, демо-объявления
npm run dev
```

Откройте http://localhost:3000

**Демо-доступы после сида**

| Роль | Телефон | Пароль |
|---|---|---|
| Администратор | `+77000000001` | `admin12345` |
| Пользователь | `+77000000002` | `demo12345` |

## Подключение оплаты

По умолчанию `PAYMENT_PROVIDER=mock` — пополнение зачисляется мгновенно, удобно для разработки.

Для боевого режима укажите в `.env`:

```env
PAYMENT_PROVIDER=kaspi          # или robokassa
PAYMENT_MERCHANT_ID=...
PAYMENT_SECRET=...
PAYMENT_WEBHOOK_SECRET=...
```

Провайдер должен слать POST на `/api/payments/webhook` с телом `{ orderId, status, externalId }` и подписью HMAC-SHA256 в заголовке `x-signature`. Вебхук идемпотентен: повторный вызов не зачислит деньги дважды.

Логика адаптера — `src/lib/payments.ts`. Чтобы добавить провайдера, допишите ветку в `createPayment`.

## Плановые задачи

`GET /api/cron/expire` гасит истёкшие продвижения, подписки и объявления. На Vercel уже настроено через `vercel.json` (раз в час). На своём сервере:

```
0 * * * * curl -H "x-cron-key: $CRON_SECRET" https://qonys.kz/api/cron/expire
```
